# Writing notes

1. Start with the topic in a few words, then a colon.
2. State the fact. Do not retell the conversation.
3. Keep it to one or two sentences.

Good: `Build: the examples are separate crates, check them one by one.`
Bad: `The user asked me about the build and I told them that the examples are separate.`
