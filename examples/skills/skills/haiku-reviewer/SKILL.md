# Reviewing a haiku

1. Count the syllables of each line.
2. Report whether the poem follows the 5-7-5 pattern.
3. Suggest one concrete fix for each line that does not.

The user specified that certain words should use a different syllable count than the default.
See `references/syllables.md` for the list of words and their specified syllable counts.
